# Security Policy

## Supported Versions

Only the latest major version of `react-prune` is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to Daniel Arikawe via [GitHub Issues](https://github.com/danieljohnson18/react-prune/issues) (or contact privately if sensitive).

**Please do not report security vulnerabilities through public GitHub issues if they are critical exploits.**

1.  We will acknowledge your report within 48 hours.
2.  We will provide an estimated timeframe for the fix.
3.  We will notify you when the fix is released.

Thank you for helping keep `react-prune` safe!
